# Sabah's Personal Portfolio

Welcome to my personal portfolio website! This project showcases my background as a Computer Science and Engineering student, my technical skills, selected projects, and creative interests.

## About Me

I am a Computer Science and Engineering student interested in software development, UI/UX design, and graphic design. I enjoy learning new technologies, building creative projects, and continuously improving my skills.

My approach is simple: **Always learning. Always creating. Always growing.**

## Features

- **Home:** Introduction, animated text, and navigation buttons.
- **About:** Personal background, interests, and approach to learning.
- **Work:** A slider showcasing selected projects.
- **Services:** An overview of my areas of interest and services.
- **Skills:** A visual presentation of my technical and creative skills.
- **My Approach:** My perspective on learning, creativity, and development.
- **Contact:** A contact form and links to connect with me.
- **Responsive Design:** A layout designed for mobile devices, tablets, and desktop screens.
- **Interactive Elements:** Animated text, scroll effects, navigation highlights, and a scroll-to-top button.

## Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, animations, and responsive design.
- **JavaScript** — Interactive features and dynamic content.
- **Devicon and Remix Icon** — Icons loaded through external CDNs.

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/sabah-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd sabah-portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, open the project in Visual Studio Code and use the Live Server extension.
